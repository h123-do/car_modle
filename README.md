# 动力之间 · 汽车传动交互实验室

一个中文汽车传动原理教学网站，通过交互实验理解燃油车和纯电车的动力传递过程。
👉 [点击进入汽车传动交互实验室](https://h123-do.github.io/-/)
## 功能

- 切换手动变速燃油车和固定减速比纯电车。
- 点击发动机、离合器、变速器、电池、逆变器、电机和车轮等部件，查看原理与实时状态。
- 调整油门、制动、挡位、离合器和道路坡度。
- 观察车速、转速、轮端转矩与车速曲线。
- 完成一挡起步、换挡、爬坡、再生制动四个引导实验。
- 支持桌面与手机布局、键盘操作和减少动态效果设置。

## 运行

用现代浏览器打开 `index.html` 即可使用。页面的样式、脚本和图形均包含在该文件中，无须安装依赖，可离线运行。延伸资料链接需要联网访问。

## 教学模型

模型基于纵向受力平衡、传动比关系和简化能量计算。两种动力系统采用相同车身参数，便于观察差异；参数与转矩曲线为教学示例，不代表具体车型。

燃油车包含起步半联动辅助，省略换挡瞬态和熄火。纯电车包含再生制动、回收功率限制、低速衰减与电量限制。详细公式、参数和简化假设见页面底部“看懂计算关系、模型边界与延伸资料”。

## 验证

已用 Edge 浏览器检查换挡转速关系、空挡及离合器断开、车辆加速、再生制动、坡度影响、电量限制与传动功率关系，并检查 320、390、768、1024 和 1440 像素宽度的布局。
